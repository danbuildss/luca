# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the work. Harassment, personal attacks and discriminatory language are not accepted in issues, pull requests, reviews or any other project space.

## Reporting

If someone's behaviour breaks this code, contact the maintainer privately through GitHub ([@danbuildss](https://github.com/danbuildss)). Reports are handled confidentially. The maintainer may remove comments, close threads or block participants who do not follow it, as described in the Contributor Covenant's enforcement guidelines.
